# Шаблон скилла платформы

```
.claude/skills/<платформа>-development/
├── SKILL.md                     правила, порядок работы, чек-лист (до ~200 строк)
└── references/
    ├── security.md              проверка подлинности данных платформы, секреты, примеры и тесты
    ├── api.md                   вызовы API платформы (SDK или Saloon-коннектор проекта), лимиты, ошибки
    ├── frontend.md              встраивание клиента: SDK, тема, навигация, вьюпорт (для мини-приложений и PWA)
    └── testing.md               фабрики подписанных данных, фейки, ручная проверка
```

## Правила написания

- Императивно и конкретно: «Проверяй подпись initData в middleware `App\Tma\Http\Middleware\VerifyTelegramInitData` до любого контроллера», а не «желательно проверять данные».
- Каждое правило — с причиной, если она неочевидна.
- Примеры кода — по раскладке и стилю проекта (ADR-001, соседние файлы), рабочие.
- Ссылки на официальную документацию — у каждого раздела, где факт может устареть.
- Не дублируй скиллы Laravel Boost и agentio — ссылайся на них.
