# Шаблоны комментариев агентов

Комментарий пишется инструментом `mcp__youtrack__add_issue_comment(issueId, text)`: так Markdown (обратные кавычки, `$`, переносы строк) доходит без искажений. Первая строка — маркер, без пробелов перед ним. Остальное — Markdown. Пиши конкретно: пути файлов, хеши коммитов, команды. Не пиши «см. выше» — комментарий должен читаться отдельно.

## Содержание

- [AGENT:START] — план и затрагиваемые файлы
- [AGENT:DECISION] — решение и отвергнутые варианты
- [AGENT:BLOCKED] — вопросы к человеку, варианты и рекомендация, как ответить
- [AGENT:DONE] — что сделано и как проверить
- [AGENT:RELEASE] — снять захват без завершения

## [AGENT:START]

Первый `[AGENT:START]` создаёт `php artisan agentio:yt claim` (строки owner/branch/worktree). Если план длинный, допиши вторым комментарием:

```markdown
[AGENT:START]
owner: `host:/abs/path/to/worktree#{{project}}-42`
branch: `{{project}}-10`
worktree: `/abs/path/to/worktree`

**Роль:** developer | orchestrator | project-manager | reviewer
**План:**
1. ...
2. ...

**Затрагиваемые файлы:**
- `app/Actions/Users/UpdateUserAvatar.php` (новый)
- `tests/Feature/Actions/Users/UpdateUserAvatarTest.php` (новый)
- `routes/web.php`

**Допущения:**
- ... (если допущение существенное и не следует из задачи или статей — это не допущение, а `[AGENT:BLOCKED]`)
```

## [AGENT:DECISION]

```markdown
[AGENT:DECISION]
**Решение:** храним аватар на диске `public`, путь в `users.avatar_path`.
**Почему:** ADR-001 ({{project}}-A-…): файлы — через Storage; одна картинка на пользователя.
**Отвергнуто:**
- Spatie Media Library — новая зависимость ради одного поля.
- Хранение в БД (blob) — нагрузка на БД, нет CDN.
**Влияние:** миграция `add_avatar_path_to_users_table`, статьи «Модель данных: Пользователи» и фичи «Профиль и аватар» ({{project}}-A-…) обновлены.
```

## [AGENT:BLOCKED]

Правила — раздел «Вопросы к человеку» скилла agentio-youtrack-workflow: все вопросы задачи в одном комментарии, **только на русском языке**, у каждого — что от него зависит, варианты и рекомендация. Первый абзац (до пустой строки) панель `/agentio` показывает как причину блокировки: в нём — коротко и понятно, что остановлено и сколько вопросов ждут ответа. Тот же комментарий целиком уходит в Telegram-бот разработчика (если он настроен); абзац «**Как ответить:**» бот заменяет своей подсказкой (ответ реплаем), а Stage для возврата берёт из строки «Stage → …» — пиши её именно так. После комментария: `php artisan agentio:yt release <ID> --state=Blocked` (если задача захвачена тобой; иначе `update_issue(issueId, customFields={"Stage": "Blocked"})`).

```markdown
[AGENT:BLOCKED]
**Что остановлено:** планирование идеи {{project}}-1 (аналитика записана; архитектура и декомпозиция ждут ответов).
**Нужен ответ:** 2 вопроса (В1–В2) — комментарием в этой задаче, затем Stage → Backlog.

**Что уже сделано:** статьи {{project}}-A-31 (новая), {{project}}-A-24; ветка `{{project}}-10`, коммиты `abc1234` — если были.

**Вопросы**

**В1. Что считать оплатой заказа при оплате частями?**
От ответа зависит: когда заказ уходит в сборку ({{project}}-A-40 BR-3), письма и сверка.
- а) Первый платёж — заказ оплачен, остаток списывается по графику. Риск: неоплаченные остатки.
- б) Только полная оплата — заказ ждёт последнего платежа. Риск: долгая сборка.
- **Рекомендация: б** — нет долгов покупателей, проще сверка; первый платёж резервирует товар.

**В2. Аватар по умолчанию?**
От ответа зависит: критерий приёмки {{project}}-12.
- а) Инициалы на цветном фоне (уже есть хук `use-initials`).
- б) Статичная картинка `public/images/avatar-default.png`.
- **Рекомендация: а** — без нового файла, различимо в списках.

**Как ответить:** комментарием в этой задаче — `В1: б; В2: а` (или свой вариант текстом), либо `Принимаю рекомендации` / `Принимаю рекомендации, кроме В2: …`. Затем верните Stage в **Backlog**. Возврат Stage без комментария = согласие со всеми рекомендациями.
```

Stage для возврата: идея — `Backlog`, EPIC/STORY/TASK — `Ready`. Вопрос без рекомендации допустим, только если агент действительно не может выбрать (например, нужны данные, которых нет в системе); тогда так и напиши: «Рекомендации нет: <почему>».
