## Контекст
Laravel-приложение, разработка ведётся автономными агентами по задачам YouTrack. Нужны явные соглашения, чтобы код разных задач выглядел одинаково.

## Решение
- **Стек и версии:** …
- **Слои:** контроллеры, Form Request, Actions или сервисы, Policy, модели …
- **Структура кода:** конвенция проекта — как раскладка задана в `CLAUDE.md`/`AGENTS.md`, `.ai/guidelines`, `.ai/rules` или устойчиво видна в коде (например, «Actions — `app/Actions`»); если её нет — доменные неймспейсы `App\<Домен>\<Вид>\<Класс>` (домен — модуль «Системной аналитики», общий код — `App\Shared\…`; плоскими остаются миграции, фабрики, сиды, `config`, `routes`, `lang`, каркас и код, который пакеты публикуют по своему пути). Тест зеркалит путь класса, набор `Feature`/`Unit` — по скиллу `testing-best-practices` (код с фреймворком — `Feature`). Смена раскладки — только решением человека …
- **Зависимости:** новые пакеты — решение человека; интеграции с сервисами без SDK — через Saloon (`saloonphp/saloon`, скилл `agentio-saloon`) …
- **Интерфейс:** Blade / SPA / API — как данные попадают в представление …
- **Очереди:** драйвер, имена очередей, ретраи …
- **Тесты:** фреймворк, требования к покрытию, полный гейт (`composer test`), конкретные тесты (`vendor/bin/pest`) …
- **Качество кода:** форматтер, статический анализ, линтеры фронтенда …
