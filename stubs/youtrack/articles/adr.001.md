## Контекст
Laravel-приложение, разработка ведётся автономными агентами по задачам YouTrack. Нужны явные соглашения, чтобы код разных задач выглядел одинаково.

## Решение
- **Стек и версии:** …
- **Слои:** контроллеры, Form Request, Actions или сервисы, Policy, модели …
- **Структура кода:** классы — в доменных неймспейсах `App\<Домен>\<Вид>\<Класс>` (домен — модуль «Системной аналитики»), без плоских `App\Actions`, `App\Models`, `App\Http\Controllers` и т. п.; общий для доменов код — `App\Shared\…`; плоскими остаются миграции, фабрики, сиды, `config`, `routes`, `lang` и каркас (`App\Providers`). Тест зеркалит неймспейс класса: `App\Users\Actions\X` → `tests/Unit/Users/Actions/XTest.php` …
- **Интерфейс:** Blade / SPA / API — как данные попадают в представление …
- **Очереди:** драйвер, имена очередей, ретраи …
- **Тесты:** фреймворк, требования к покрытию, полный гейт (`php artisan agentio:test --full`) …
- **Качество кода:** форматтер, статический анализ, линтеры фронтенда …
