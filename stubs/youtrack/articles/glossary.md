> Термины предметной области и процесса. Новые термины добавляет скилл `agentio-system-analyst` с пометкой источника.

| Термин | Определение | Источник |
|---|---|---|
| Идея | Сырой запрос человека (`[IDEA]`), вход для планирования. | — |
| Отложенная идея | Идея с меткой `parked`: агенты проводят только системный анализ и складывают его в статью «Идеи», в разработку она идёт после решения человека. | — |
| Пауза эпика | Эпик в статусе `On Hold`: агенты его не берут, захват, ветка и worktree сохраняются до снятия паузы. | — |
| Эпик | Законченная ценность для пользователя (`[EPIC]`): одна ветка с именем ID эпика (`{{project}}-10`) от `{{base_branch}}`, один worktree. | — |
| История | Один пользовательский сценарий с критериями приёмки Given/When/Then (`[STORY]`). | — |
| Задача | Атомарное изменение для одного агента-разработчика (`[TASK]`). | — |
